# Product scope

The implemented workspace accepts historical accepted/rejected invoice examples, customer-specific rules, rule rehearsal and CSV batch checking. Versioned publication separates draft rules from active rules. Manual recovery imports validate their contents and cannot activate rules automatically.

The documented pilot supports one operator workspace and USD amounts, with explicit limits on customers, rules, examples and batch size. It has no model calls, PDF parsing, attachment verification, accounting integration, customer messaging, payment collection, team collaboration or scheduled backup.

The source describes a private deployment. Commercial demand, seller/contact details, launch readiness and production operations remain separate work. Illustrative demo data and value calculations are not customer outcomes.
